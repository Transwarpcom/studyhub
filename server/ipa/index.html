怎么装

  1. 下载上面的 .ipa
  2. 用 TrollStore（已越狱/有 TrollStore 的设备）直接打开安装
  3. 或者用 AltStore / Sideloadly / Esign / Scarlet 自签后安装
  4. 首次打开如果提示「未受信任的开发者」，去 设置 → 通用 → VPN与设备管理 里信任证书

装完之后

  1. 打开就是课程文件夹树，接口地址和口令已经内置，不用填
  2. 下拉刷新拉最新内容，读过的章节会自动缓存，断网也能看
  3. 「答疑」页可以拍照 / 选 PDF 传题目，讲解会回到这里
如果内容拉不下来，进「设置」检查接口地址是否为 study-api 结尾。
