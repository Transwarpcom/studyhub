在第二节例1及例2中，我们看到收敛数列不一定是单调的.因此，准则Ⅱ所给出的单调有界这条件，是数列收敛的充分条件，而不是必要的.当然，其中有界这一条件对数列的收敛性来说是必要的.下面叙述的柯西极限存在准则，它给出了数列收敛的充分必要条件

柯西极限存在准则数列 $\{ x _ { n } \}$ 收敛的充分必要条件是：对于任意给定的正数ε，存在正整数N，使得当 $m > N , n > N$ 时，有

$$

$$

证必要性设 $\operatorname* { l i m } _ { n \to \infty } x _ { n } = a , \forall \varepsilon > 0$ ，由数列极限的定义，正整数N，当 $n { > } N$ 时,有

$$
\vert x _ { n } - a \vert < \frac { \varepsilon } { 2 } ;
$$

同样，当 $m { > } N$ 时，也有

$$
\vert x _ { m } - a \vert < \frac { \varepsilon } { 2 } .
$$

因此，当 $m > N , n > N$ 时，有

$$
\left| x _ { n } - x _ { m } \right| = \mid \left( x _ { n } - a \right) - \left( x _ { m } - a \right) \mid \leqslant \left| x _ { n } - a \right| + \left| x _ { m } - a \right| < { \frac { \varepsilon } { 2 } } + { \frac { \varepsilon } { 2 } } = \varepsilon ,

所以条件是必要的.

充分性这里不予证明.

## 一、函数的连续性

自然界中有许多现象，如气温的变化、河水的流动、植物的生长等都是连续地变化着的.这种现象在函数关系上的反映，就是函数的连续性.例如就气温的变化来看，当时间变动很微小时，气温的变化也很微小，这种特点就是所谓连续性.下面我们先引人增量的概念，然后来描述连续性，并引出函数的连续性的定义.

设变量u从它的一个初值 $u _ { 1 }$ 变到终值 $u _ { 2 }$ ，终值与初值的差 ${ \boldsymbol { u } } _ { 2 } - { \boldsymbol { u } } _ { 1 }$ 就叫做变量u的增量，记作 $\Delta u$ ,即

$$
\Delta u = u _ { 2 } - u _ { 1 } .
$$

增量 $\Delta u$ 可以是正的，也可以是负的.在 $\Delta u$ 为正的情形，变量u从 $u _ { 1 }$ 变到 $u _ { 2 } = u _ { 1 } +$ △u时是增大的；当 $\Delta u$ 为负时，变量u是减小的.

应该注意到：记号△u并不表示某个量△与变量u的乘积，而是一个整体不可分 $\Delta u$ 割的记号.

## 一、连续函数的和、差、积、商的连续性

由函数在某点连续的定义和极限的四则运算法则，立即可得出下面的定理：

定理1设函数f（x）和g（x）在点 $\scriptstyle { \mathfrak { x } } _ { 0 }$ 连续，则它们的和（差）fg、积f·g及商 $\frac { f } { g }$ （当 $g ( x _ { 0 } ) \neq 0$ 时）都在点 $\scriptstyle { x _ { 0 } }$ 连续.

## 二、反函数与复合函数的连续性

反函数和复合函数的概念已经在第一节中讲过，这里来讨论它们的连续性.

证明从略.

例2由于 $y = \sin { x }$ 在闭区间 $\left[ - \frac { \pi } { 2 } , \frac { \pi } { 2 } \right]$ 上单调增加且连续，所以它的反函数 $y =$ arcsinx在闭区间 $[ - 1 , 1 ]$ 上也是单调增加且连续的.

## 三、初等函数的连续性

前面证明了三角函数及反三角函数在它们的定义域内是连续的.

我们指出（但不详细讨论），指数函数 $\gamma = a ^ { \ast } \left( a > 0 , a \neq 1 \right)$ 对于一切实数x都有定义，且在区间 $( - \infty , + \infty )$ 内是单调的和连续的，它的值域为 $( 0 , + \infty )$

由指数函数的单调性和连续性，引用定理2可得：对数函数 $\gamma = \log _ { a } \textit { x } ( a > 0$ $a \neq 1 )$ 在区间 $( 0 , + \infty )$ 内单调且连续

幂函数 $\gamma = x ^ { \mu }$ 的定义域随 $\mu$ 的值而异，但无论 $\mu$ 为何值，在区间 $( 0 , + \infty )$ 内幂函数总是有定义的.下面我们来证明，在 $( 0 , + \infty )$ 内幂函数是连续的.事实上，设 $x { > } 0$ ,则

$$
\gamma = x ^ { \mu } = a ^ { \mu \mathrm { l o g } _ { a } x } ,
$$

因此，幂函数 $x ^ { \mu }$ 可看作是由 $y = a ^ { \mathrm { * } } , u = \mu \log _ { a } x$ 复合而成的，由此，根据定理4，它在$( 0 , + \infty )$ 内连续.如果对于μ取各种不同值加以分别讨论，可以证明（证明从略）幂函 $\mu$

数在它的定义域内是连续的.

综合起来得到：基本初等函数在它们的定义域内都是连续的，

最后，根据第一节中关于初等函数的定义，由基本初等函数的连续性以及本节定理1、定理4可得下列重要结论：一切初等函数在其定义区间内都是连续的.所谓定义区间，就是包含在定义域内的区间.

根据函数f（x）在点 $\scriptstyle { x _ { 0 } }$ 连续的定义，如果已知 $f ( x )$ 在点 $\scriptstyle { x _ { 0 } }$ 连续，那么求$f ( x )$ 当 $\scriptstyle x \longrightarrow x _ { 0 }$ 的极限时，只要求f（x）在点x0的函数值就行了.因此，上述关于初等函数 $\scriptstyle { \mathfrak { x } } _ { 0 }$ 连续性的结论提供了求极限的一个方法，这就是：如果f（x）是初等函数，且xo是 $\scriptstyle { \boldsymbol { x } } _ { 0 }$ $f ( x )$ 的定义区间内的点，那么

$$
\operatorname* { l i m } _ { x \to x _ { 0 } } f ( x ) = f ( x _ { 0 } ) .
$$

例如，点 $x _ { 0 } = 0$ 是初等函数 $f ( x ) = \sqrt { 1 - x ^ { 2 } }$ 的定义区间 $[ - 1 , 1 ]$ 上的点，所以$\operatorname* { l i m } _ { x \to 0 } \sqrt { 1 - x ^ { 2 } } = \sqrt { 1 } = 1$ ；又如点 $x _ { 0 } = \frac { \pi } { 2 }$ 是初等函数 $f ( x ) = \ln \sin x$ 的一个定义区间 $( 0 , \pi )$ 内的点，所以

$$
\operatorname* { l i m } _ { x \to { \frac { \pi } { 2 } } } \ln \sin x = \ln \sin { \frac { \pi } { 2 } } = 0 .
$$

例5求 $\operatorname* { l i m } _ { s \to 0 } { \frac { \log _ { a } ( 1 + x ) } { x } } \left( a > 0 , a \neq 1 \right)$

例7求 $\operatorname* { l i m } _ { x \to 0 } { \frac { ( 1 + x ) ^ { \alpha } - 1 } { x } } { \big ( } \alpha \in \mathbb { R } { \big ) }$
