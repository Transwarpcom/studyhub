## 二、导数的定义

## 1.函数在一点处的导数与导函数

从上面所讨论的两个问题看出，非匀速直线运动的速度和切线的斜率都归结为如下的极限：

$$
\operatorname* { l i m } _ { x \to x _ { 0 } } { \frac { f ( x ) - f ( x _ { 0 } ) } { x - x _ { 0 } } } ,\tag{1-3}
$$

这里 $\scriptstyle x - x _ { 0 }$ 和 $f ( x ) - f ( x _ { 0 } )$ 分别是函数 $\scriptstyle y = f ( x )$ 的自变量的增量 $\Delta x$ 和函数的增量 $\Delta y$

$$
\Delta x = x - x _ { 0 } , \Delta y = f ( x ) - f ( x _ { 0 } ) = f ( x _ { 0 } + \Delta x ) - f ( x _ { 0 } ) .
$$

因 $x \longrightarrow x _ { 0 }$ 相当于 $\Delta x {  } 0$ ，故（1-3）式也可写成

$$
\operatorname* { l i m } _ { \Delta x \to 0 } \frac { \Delta y } { \Delta x } \quad \xrightarrow [ \Delta x ] { = \Delta } \quad \operatorname* { l i m } _ { \Delta x \to 0 } \frac { f ( x _ { 0 } + \Delta x ) - f ( x _ { 0 } ) } { \Delta x } ,
$$

在自然科学和工程技术领域内，还有许多概念，例如电流强度、角速度、线密度等，都可归结为形如（1-3）式的数学形式.我们撇开这些量的具体意义，抓住它们在数量关系上的共性，就得出函数的导数概念.

定义设函数 $y = f ( x )$ 在点 $x _ { 0 }$ 的某个邻域内有定义，当自变量x在 $x _ { 0 }$ 处取得增量$\Delta x ($ 点 $x _ { 0 } + \Delta x$ 仍在该邻域内）时，相应地，因变量取得增量 $\Delta y = f ( x _ { 0 } + \Delta x ) - f ( x _ { 0 } )$ ；如果$\Delta y$ 与 $\Delta x$ 之比当 $\Delta x {  } 0$ 时的极限存在，那么称函数 $y = f ( x )$ 在点 $x _ { 0 }$ 处可导，并称这个极限为函数 $\scriptstyle y = f ( x )$ 在点 $x _ { 0 }$ 处的导数，记为 $f ^ { \prime } ( x _ { 0 } )$ ，即

$$
f ^ { \prime } ( x _ { 0 } ) = \operatorname* { l i m } _ { \Delta x  0 } \frac { \Delta y } { \Delta x } { = } \operatorname* { l i m } _ { \Delta x  0 } \frac { f ( x _ { 0 } + \Delta x ) - f ( x _ { 0 } ) } { \Delta x } ,\tag{1-4}
$$

也可记作 $y ^ { \prime } \mid _ { s = x _ { 0 } } ,  { \frac { \mathrm { d } y } { \mathrm { d } x } } | _ { s = x _ { 0 } } { \frac { { \exists } { \hat { x } } } { \mathrm { d } x } } { \frac { \mathrm { d } f ( x ) } { \mathrm { d } x } } | _ { s = x _ { 0 } }$

函数 $f ( x )$ 在点 $\scriptstyle { x _ { 0 } }$ 处可导有时也说成f（x)在点 $\boldsymbol { x } _ { 0 }$ 处具有导数或导数存在.

导数的定义式（1-4）也可取不同的形式，常见的有

$$
f ^ { \prime } ( x _ { 0 } ) = \operatorname* { l i m } _ { h  0 } { \frac { f ( x _ { 0 } + h ) - f ( x _ { 0 } ) } { h } }\tag{1-5}
$$

和

$$
f ^ { \prime } ( x _ { 0 } ) = \operatorname* { l i m } _ { x \to x _ { 0 } } { \frac { f ( x ) - f ( x _ { 0 } ) } { x - x _ { 0 } } } .\tag{1-6}
$$

（1-5）式中的h即自变量的增量 $\Delta x$

在实际中，需要讨论各种具有不同意义的变量的变化“快慢”问题，在数学上就是所谓函数的变化率问题导数概念就是函数变化率这一概念的精确描述.它撇开了自变量和因变量所代表的几何或物理等方面的特殊意义，纯粹从数量方面来刻画变化率的本质：因变量增量与自变量增量之比 $\frac { \Delta { y } } { \Delta { x } }$ 是因变量y在以 $\scriptstyle x _ { 0 }$ 和 $x _ { 0 } + \Delta x$ 为端点的区间上的平均变化率，而导数 $f ^ { \prime } ( x _ { 0 } )$ 则是因变量y在点 $\scriptstyle { x _ { 0 } }$ 处的变化率，它反映了因变量随自变量的变化而变化的快慢程度.

如果极限（1-4）不存在，就说函数 $y = f ( x )$ 在点 $\scriptstyle { \mathfrak { x } } _ { 0 }$ 处不可导.如果不可导的原因是由于 $\Delta x {  } 0$ 时，比式 $\frac { \Delta y } { \Delta x }  \infty$ ，为了方便起见，也往往说函数 $\scriptstyle y = f ( x )$ 在点 $x _ { 0 }$ 处的导数为无穷大

上面讲的是函数在一点处可导.如果函数 $y = f ( x )$ 在开区间I内的每点处都可导，那么就称函数f（x)在开区间I内可导.这时，对于任一 $x \in I$ ，都对应着f（x）的一个确定的导数值.这样就构成了一个新的函数，这个函数叫做原来函数 $\scriptstyle y = f ( x )$ 的导函数，记作y'，f'（x）， $\frac { \mathrm { d } { } y } { \mathrm { d } { } x }$ 或 $\frac { \mathrm { d } f ( \boldsymbol { x } ) } { \mathrm { d } \boldsymbol { x } }$

在(1-4)式或(1-5)式中把 $\scriptstyle { x _ { 0 } }$ 换成𝑥，即得导函数的定义式

$$
y ^ { \prime } = \operatorname* { l i m } _ { \Delta x  0 } { \frac { f ( x + \Delta x ) - f ( x ) } { \Delta x } }
$$

或

$$
f ^ { \prime } ( x ) = \operatorname* { l i m } _ { h \to 0 } { \frac { f ( x + h ) - f ( x ) } { h } } .
$$

注意在以上两式中，虽然x可以取区间I内的任何数值，但在极限过程中，x是常量， $\Delta x$ 或h是变量.

显然，函数 $f ( x )$ 在点 $\scriptstyle { x _ { 0 } }$ 处的导数 $f ^ { \prime } ( x _ { 0 } )$ 就是导函数 $f ^ { \prime } ( x )$ 在点 $\scriptstyle x = x _ { 0 }$ 处的函数值，即

$$
f ^ { \prime } ( x _ { 0 } ) = f ^ { \prime } ( x ) \mid _ { x = x _ { 0 } } .
$$

导函数 $f ^ { \prime } ( x )$ 简称导数，而 $f ^ { \prime } ( x _ { 0 } )$ 是 $f ( x )$ 在 $\scriptstyle { x _ { 0 } }$ 处的导数或导数 $f ^ { \prime } ( x )$ 在点 $\scriptstyle { \mathfrak { x } } _ { 0 }$ 处的值

## 3.单侧导数

根据函数f（x）在点 $\scriptstyle x _ { 0 }$ 处的导数 $f ^ { \prime } ( x _ { 0 } )$ 的定义，导数

$$
f ^ { \prime } ( x _ { 0 } ) = \operatorname* { l i m } _ { h  0 } { \frac { f ( x _ { 0 } + h ) - f ( x _ { 0 } ) } { h } }
$$

是一个极限，而极限存在的充分必要条件是左、右极限都存在且相等，因此 $f ^ { \prime } ( x _ { 0 } )$ 存在即f（x）在点 $\scriptstyle { x _ { 0 } }$ 处可导的充分必要条件是左、右极限

$$
\operatorname* { l i m } _ { h \to 0 ^ { - } } { \frac { f ( x _ { 0 } + h ) - f ( x _ { 0 } ) } { h } } \quad { \mathbb { Z } } \quad \operatorname* { l i m } _ { h \to 0 ^ { + } } { \frac { f ( x _ { 0 } + h ) - f ( x _ { 0 } ) } { h } }
$$

都存在且相等.这两个极限分别称为函数f（x）在点x0处的左导数和右导数，记作 $\scriptstyle { x _ { 0 } }$ $f _ { - } ^ { \prime } ( x _ { 0 } )$ 及 $f _ { \ast } ^ { \prime } ( x _ { 0 } )$ ，即

$$
f _ { - } ^ { \prime } ( x _ { 0 } ) = \operatorname* { l i m } _ { h  0 ^ { - } } { \frac { f ( x _ { 0 } + h ) - f ( x _ { 0 } ) } { h } } ,
$$

$$
f _ { * } ^ { \prime } ( x _ { 0 } ) = \operatorname* { l i m } _ { h \to 0 ^ { * } } { \frac { f ( x _ { 0 } + h ) - f ( x _ { 0 } ) } { h } } .
$$

现在可以说，函数f（x）在点x处可导的充分必要条件是左导数 $\scriptstyle { x _ { 0 } }$ $f _ { - } ^ { \prime } ( x _ { 0 } )$ 和右导数$f _ { \ast } ^ { \prime } ( x _ { 0 } )$ 都存在且相等

函数 $f ( x ) = \left| x \right.$ 在x=0处的左导数 $f _ { - } ^ { \prime } ( 0 ) = - 1$ 及右导数 $f ^ { \prime } ( 0 ) = 1$ 虽然都存在，但不相等，故 $f ( x ) = \left| { x } \right|$ 在x=0处不可导.

左导数和右导数统称为单侧导数

如果函数 $f ( x )$ 在开区间（a，b）内可导，且 $f _ { \ast } ^ { \prime } ( a )$ 及f(b)都存在，那么就说f（x）在闭区间[a，b]上可导

## 四、函数可导性与连续性的关系

$$

存在.由具有极限的函数与无穷小的关系知道，

$$
\frac { \Delta y } { \Delta x } = f ^ { \prime } ( x ) + \alpha ,
$$

其中 $\alpha$ 为当 $\Delta x {  } 0$ 时的无穷小.上式两边同乘 $\Delta x$ ，得

$$
\Delta y = f ^ { \prime } ( x ) \Delta x + \alpha \Delta x .
$$
